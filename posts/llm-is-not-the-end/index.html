LLM is not the End

2026年8月23日 · 1 分钟 · LuC

我认同 Rich Sutton 的观点：大语言模型并不是人工智能的最终形态。

语言并不是智能的基础，而只是智能发展出来的一种表达和交流工具。人类可以用语言描述目标，但并不意味着目标必须通过语言产生。一个婴儿不会说话，却依然知道饥饿、寻找食物并采取行动。动物也没有语言，但它们依然能够通过感知世界、行动和反馈来学习。

如果人工智能的目标是创造接近生物智能的系统，那么它最终不应该只是一个语言模型。因为自然界中的智能都不是通过语言产生的，而是在与环境不断交互的过程中形成的。

智能的本质在于实现目标，而实现目标需要直接接触世界。智能体通过行动获得反馈，判断哪些行为有效，哪些行为无效，并不断调整自身。这种基于奖励和反馈的学习方式，才是生命智能的核心。

相比之下，大语言模型主要从语言中学习。语言并不是世界本身，而只是人类对世界的抽象描述。它能够传递信息，却无法完整包含现实世界的复杂性。因此，仅依靠语言训练的模型，本质上是在学习世界的符号表示，而不是直接学习世界。

这就像一个只会 Python 的程序员。他可以写出复杂的软件，但并不一定理解计算机底层的运行机制。Python 是对计算机的一层抽象，而机器码和硬件才更接近计算机真正的本质。同样，语言只是智能的一种抽象表达，而不是智能本身。

因此，当前的大语言模型更像是一种强大的符号处理工具。它能够在语言和知识领域展现惊人的能力，但它并不等同于生物意义上的完整智能。

真正的智能体应该像生命一样，通过直接与世界互动来学习。例如，一个婴儿感到饥饿时会哭，并不是因为他在脑中用语言推理“我饿了，所以我要哭”，而是因为身体需求驱动行为。如果他发现爬向食物能够满足需求，他就会逐渐学会这种行为；如果行为无法获得反馈，他也会调整策略。

未来的人工智能不仅需要理解语言，更需要拥有感知世界、采取行动、获得反馈并持续学习的能力。只有这样，它才可能真正接近生命所展现出的智能。

毕竟，我们不应忘记：生命，是世界为“智能”这个问题交出的唯一答卷。
